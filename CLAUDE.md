# Working rules for Claude in this repo

- Work locally first, in this repository.
- For every meaningful change (new feature, new question set, refactor, anything beyond a typo),
  create a local branch from an up-to-date `main`: `<type>/<short-topic>`, e.g. `feat/quiz-compose-questions`.
- Commit locally with clear messages. Do NOT push and do NOT open a PR until Maxim explicitly approves.
- After approval: push the branch and open a PR with `gh pr create`; share the PR link.
- Never push to `main` directly, never force-push, never merge without Maxim.
- Interview content (questions, answers, cheat sheets) is in English; chat with Maxim can be in Russian.
